# Chapter 1: Foundations of Machine Learning

A short summary of what this chapter covers and why it matters.

## Learning Objectives
After completing this chapter, you will be able to:

- Explain what machine learning is and distinguish its main types.
- Split data correctly into training, validation, and test sets.
- Recognize and diagnose overfitting and underfitting.
- Explain the bias-variance tradeoff and the role of regularization.
- Evaluate models using cross-validation and appropriate metrics.
- Tune hyperparameters and avoid data leakage.

## Prerequisites
This chapter assumes only a modest background:

- **Python basics:** variables, loops, functions, lists, and dictionaries.
- **Introductory mathematics:** high-school algebra, functions, and graphs.
- **Basic statistics:** mean, variance, standard deviation, and the idea of a data distribution.
