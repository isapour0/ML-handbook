# ML-handbook
A practical guide and tutorial covering selected classical machine learning topics and algorithms.

## About this project

This repository organizes core machine learning topics into a coherent learning resource. Each topic is built by studying and synthesizing multiple technical and educational sources, with an emphasis on conceptual understanding, mathematical explanations and comparisons between algorithms.

The handbook focuses on classical machine learning. Deep learning is outside its main scope, but a short roadmap for continuing in that direction is provided at the end.

The goal is to organize these topics into a coherent learning resource that helps readers understand not only how algorithms work, but also their assumptions, strengths, limitations, and potential applications.

## Learning Objectives

By working through this handbook, readers will be able to:

- Important ML algorithms and concepts
- Connect mathematical formulations with their underlying intuition.
- Compare algorithms and identify their appropriate use cases.
- Explore practical implementations using Python and relevant libraries.
- Build a solid foundation for further study in AI.

> [!IMPORTANT]
> Recommended Learning Path:
> For those who are studying these topics for the first time, the order in the table of contents is suitable. However, those who have previous experience can go directly to the topics that are relevant to their goals.

### How Each Topic Is Organized
Every topic folder contains a `README.md` (theory) and a Jupyter notebook (implementation), structured as follows:
1. **Conceptual Overview:** the core idea behind the algorithm and the problem it solves.
2. **Mathematical Foundations:** relevant equations, notation, and explanations.
3. **Algorithm Analysis:** strengths, limitations, assumptions, and guidance on when to use it.
4. **Practical Implementation**
5. **Resources:** Articles, documentation, and research papers (links will be provided under each topic)

### Prerequisites
A basic understanding of Python is recommended. Familiarity with introductory mathematics, statistics, and linear algebra will also be helpful. as well as basic understanding of libraries such as:
- Numpy
- Pandas
- Matplotlib
- scikit-learn
